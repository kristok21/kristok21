## Why this exists

Most profiles list tools.  
This one is the **spec sheet** for a frontend developer who treats UI like product.

> I don’t decorate screens.  
> I design **systems** — typed, accessible, fast — that people trust enough to open twice.

### `beforePaint()`

I map the **tree**, the **data**, the **edges**.  
Architecture first — pretty debt never.

```ts
type Ship = {

  accessible: true;
  maintainable: true;
```

### `afterCommit()`

Hooks that compose. Forms that forgive.  
Motion that **guides**, never shouts.
